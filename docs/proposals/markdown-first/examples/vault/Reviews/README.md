# Reviews

这里保存人类对待审判断的回应草稿；它不是来源摄入区，也不是确认 receipt。只有用户在当前 Agent 对话中明确授权，系统才把一份回应应用到受管合同，并记录新的 revision。

`Views/Review.md` 和 `Views/Review.base` 只是可重建的待审队列。没有 Obsidian、Bases 或 CLI 时，仍可直接阅读本目录和静态 Markdown。
